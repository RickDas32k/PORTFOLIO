# Rick Das portfolio (Next.js)
1. `npm install`
2. Put your photo at `public/rick.jpg` (portrait, 4:5 works best). It gets the red duotone automatically.
3. Put your resume at `public/resume.pdf` (the two Resume buttons download it as Rick-Das-Resume.pdf)
4. `npm run dev`, then open http://localhost:3000
5. Deploy: push to GitHub and import the repo in Vercel.
Edit all content in `lib/data.js`.
